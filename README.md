# burger-support

Бот поддержки Burger VPN. Этап 1: пользователь пишет боту → в форум-группе поддержки
создаётся топик на пользователя, сообщения пересылаются туда; ответы админов из топика
уходят пользователю. Без AI и без внешних API.

Этап 2: ИИ-ассистент первой линии на Gemini. Выясняет причину по чек-листам базы знаний
(просит скрины, логи, регион и оператора), читает скриншоты, PDF-чеки и голосовые, видит данные
подписки клиента из панели Remnawave (только чтение). Ничего не меняет в системе: всё, что требует
админки, собирает и передаёт человеку с тегом из `ADMIN_TAGS`.

База знаний — `kb/knowledge.md` (выжимка из методички поддержки). В git её нет: на сервер
копируется отдельно и монтируется в контейнер.

Админ-команды в группе:
- `/delete` — закрыть заявку (удалить топик), `/s` — обновить карточку клиента;
- `/stop`, `/start` — выключить/включить ИИ в этом топике;
- `/pauseai`, `/resumeai` — выключить/включить ИИ везде (после деплоя ИИ выключен, пока не дать `/resumeai`);
- `/outage <что случилось>` — массовый сбой: ИИ отвечает шаблоном про техработы и копит список писавших;
  `/outage off` — сбой закончился, бот выдаёт список для компенсации.

Запуск: заполнить `.env` (см. `.env.example`), затем `docker compose up -d --build`
или локально `uv run python -m app.main`.
