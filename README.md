# burger-support

Бот поддержки Burger VPN. Этап 1: пользователь пишет боту → в форум-группе поддержки
создаётся топик на пользователя, сообщения пересылаются туда; ответы админов из топика
уходят пользователю. Без AI и без внешних API.

Админ-команды в группе: `/delete` — закрыть заявку (удалить топик), `/s` — обновить карточку клиента.

Запуск: заполнить `.env` (см. `.env.example`), затем `docker compose up -d --build`
или локально `uv run python -m app.main`.
